**Análisis de Conversión y Prueba A/B para Sistema de Recomendaciones** – TripleTen | 2025

Descripción: El objetivo del proyecto fue evaluar el impacto de un sistema de recomendaciones mejorado en una tienda online, midiendo si lograba incrementar en al menos un 10% la conversión en las etapas clave del embudo de ventas: vista de producto, agregado al carrito y compra. Se implementó una prueba A/B para comparar el rendimiento entre usuarios con y sin el sistema mejorado.

Responsabilidades:

- Procesar y limpiar datasets de usuarios, marketing y eventos, asegurando consistencia en fechas y valores nulos.
- Filtrar y unir tablas para construir un dataframe final con condiciones específicas de región y periodo de observación.
- Calcular tasas de conversión en cada etapa del embudo para los grupos de prueba A y B.
- Realizar análisis exploratorio de distribución de eventos, actividad temporal y posibles outliers.
- Aplicar pruebas estadísticas (Z-test para proporciones) para validar diferencias significativas entre grupos.
  
Logros:

- Demostré que el grupo con sistema de recomendaciones mejorado (Grupo A) presentó mayor rendimiento en todas las etapas del embudo.
- Identifiqué un incremento notable en la conversión de página a compra (60% vs. 33% en Grupo B).
- Detecté patrones de comportamiento como baja actividad en días festivos y picos de interacción en fechas específicas.
- Aporté evidencia cuantitativa para respaldar la implementación del sistema de recomendaciones como estrategia de optimización de ventas.
